# Web Project Siap Deploy - Administrasi Server

Aplikasi PHP sederhana untuk data mahasiswa menggunakan MariaDB/MySQL.

## XAMPP
1. Buat/import database `db_kampus` menggunakan `database.sql`.
2. Simpan folder project di `htdocs`.
3. Ubah `config.php` bila username/password database XAMPP berbeda.
4. Akses `http://localhost/web-kampus/`.

## Ubuntu + Nginx
Project ini dapat di-push ke GitHub lalu di-clone ke Ubuntu Server.
Sesuaikan `config.php` dengan database/user MariaDB di server.
